## Case Study 3: International Energy Company — OT/ICS Security


    |  Industry | Energy / Utilities |

    |  Location | Europe (18 countries) |

    |  Device Count | 12,000 OT devices (PLCs, RTUs, HMIs, historian servers) |

    |  Challenge | IEC 62443 certification required for grid operator license renewal. No existing tool could discover or assess OT protocols (Modbus, DNP3, IEC 61850). |

    |  Solution | INFER™ Enterprise (Private Cloud deployment) + SD-EDGE v2.5 with DNP3/IEC 61850 support + Palo Alto Cortex XSOAR integration |

    |  Results |

        - IEC 62443 SL-2 certification achieved 4 months ahead of schedule
        - 3 legacy PLCs identified running firmware with known RCE vulnerabilities (CVE-2023-29158) — patched before exploitation
        - Mean time to detect (MTTD) for OT anomalies reduced from "unknown" to 8 minutes
