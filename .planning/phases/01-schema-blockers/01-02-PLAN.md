    ```python
    class ChangeItem(BaseModel):
        """Structured proposal for a single Confluence page change.

        Fields transcript_evidence, confidence, risk, and verifier_note have safe
        defaults so existing Supabase rows (which lack these columns) can be read
        in Phase 1 without validation errors. Phase 2 agents will populate them.
        """
        id: int
        change_type: str
        page_id: Optional[str] = None
        page_title: str
        section_heading: Optional[str] = None
        before_content: Optional[str] = None
        after_content: Optional[str] = None
        timestamp: str
        session_id: str
        status: str = "pending"
        source: Optional[str] = None
        rationale: Optional[str] = None
        generation_query: Optional[str] = None
        # --- Phase 2 verifier fields (safe defaults for Phase 1 backward-compat) ---
        transcript_evidence: List[str] = []
        confidence: Literal["high", "medium", "low"] = "low"
        risk: Literal["safe", "review", "risky"] = "safe"
        verifier_note: Optional[str] = None
    ```

    Important implementation notes:
    - Place this class AFTER MeetingChatRequest, BEFORE the _bearer_token function.
    - The Literal type annotation enforces enum validation — any value outside
      ["high","medium","low"] for confidence or ["safe","review","risky"] for risk
      will raise a Pydantic ValidationError at instantiation time.
    - transcript_evidence uses `List[str] = []` (mutable default is safe in Pydantic
      because Pydantic copies defaults per-instance).
    - Do not change any other code in this task — the dict builders are updated in Task 2.
