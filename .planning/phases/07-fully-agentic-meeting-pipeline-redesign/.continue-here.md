<decisions_made>

- **Transcript-first .md format**: No LLM per flush — raw "Speaker: text" lines appended directly.
  One LLM call at disconnect generates goals/key_decisions/conclusions for the Meeting Summary section.
  Why: cheaper, cleaner, readable live during meeting.

- **MeetingMetadataAgent called at disconnect**: Full transcript in memory (`_full_transcript_lines`)
  passed in one shot. `_sentence_buffer` is periodically cleared; `_full_transcript_lines` accumulates
  all lines throughout the meeting and is cleared only at disconnect reset.

- **Pre-filter skip-LLM guard**: Only skip the LLM when pre-filtering *actually narrowed the list*
  (i.e., `len(entries) < len(all_entries)`). If we start with 1 entry and no filter applied, still
  call LLM to check relevance (the single meeting might not match the query at all).

- **`full_transcript` not `summary_text`**: AnswerAgent checks for `full_transcript` first and labels
  it correctly so the LLM knows it has complete content. Pinecone path unchanged.

- **_speak_lock scope**: Held for the full duration of speak_chunked()/stream loop so multi-sentence
  responses are never interrupted. "Yes?" ack also serialized through the same lock.
</decisions_made>
