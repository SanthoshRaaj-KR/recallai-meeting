# Plan 03-02: Ingestion Wiring

## Goal

`jarvis.py` automatically triggers the full ingestion pipeline on Recall.ai meeting end (WebSocket disconnect), and exposes a `/summarize` Slack slash command that triggers the same pipeline on demand — both paths write to disk and conditionally upsert to Pinecone.

## Context

Plan 03-01 produced `agents/summarizer.py` with `SummarizerAgent`. This plan wires that agent into `jarvis.py`.

**Existing `jarvis.py` structure (must not break):**
- `state = MeetingState()` — global meeting state, holds transcript log
- `@app.websocket("/recall-audio-stream")` — transcript WebSocket handler; raises `WebSocketDisconnect` on disconnect
- `@app.get("/health")` — health check endpoint
- `state.get_transcript()` — returns formatted `"Speaker: utterance\n"` string
- `state.get_bot_id()` — returns current Recall.ai bot_id or None

**New infrastructure to add to `jarvis.py`:**

1. Read these new env vars (with `.env` loading already present via `load_dotenv()`):
   - `PINECONE_API_KEY` — for `PineconeClient`
   - `PINECONE_INDEX_NAME` — default `"meeting-memory"`
   - `SLACK_BOT_TOKEN` — for Slack Bolt
   - `SLACK_SIGNING_SECRET` — for Slack Bolt request verification
   - `SLACK_CHANNEL_ID` — the channel the bot posts summaries to
   - `MEETING_CHANNEL_NAME` — human-readable channel name (default `"general"`)

2. Initialize at module level (after env loading):
   ```python
   from storage.metadata_store import MetadataStore
   from storage.pinecone_client import PineconeClient
   from agents.summarizer import SummarizerAgent
   from slack_bolt.async_app import AsyncApp
   from slack_bolt.adapter.fastapi.async_handler import AsyncSlackRequestHandler

   metadata_store = MetadataStore(base_dir="./meetings")
   pinecone_client = PineconeClient(
       api_key=PINECONE_API_KEY,
       index_name=PINECONE_INDEX_NAME,
   )
   summarizer = SummarizerAgent()
   slack_app = AsyncApp(token=SLACK_BOT_TOKEN, signing_secret=SLACK_SIGNING_SECRET)
   slack_handler = AsyncSlackRequestHandler(slack_app)
   ```

3. A shared `run_ingestion_pipeline()` async function that both triggers share.

**Slack Bolt in FastAPI:** Slack Bolt's `AsyncApp` must be mounted into FastAPI via `AsyncSlackRequestHandler`. All Slack events (slash commands, etc.) go through a single POST route mounted at `/slack/events`. The Bolt SDK verifies the Slack signing secret automatically.

**`slack_bolt` is not in `requirements.txt` yet.** Add `slack-bolt==1.21.3` to `requirements.txt` before implementing.

**Step 4 — Define `run_ingestion_pipeline()`** (new function, place in a new `# INGESTION PIPELINE` section after the TOOLS section):

```python
async def run_ingestion_pipeline(transcript: str, meeting_meta: dict) -> MeetingRecord:
    """
    Run the full ingestion pipeline: summarize -> write disk -> conditionally upsert Pinecone.

    Args:
        transcript: Raw formatted transcript string ("Speaker: text\n...").
        meeting_meta: Dict with meeting_id, channel_id, channel_name, start_ts,
                      end_ts, duration_seconds, participants.

    Returns:
        The stored MeetingRecord.
    """
    record = await summarizer.run(transcript=transcript, meeting_meta=meeting_meta)
    await metadata_store.write(record)
    logger.info("Wrote meeting record to disk: %s", record.meeting_id)

    if record.status == "complete" and pinecone_client is not None:
        pinecone_client.upsert_meeting(record)
        logger.info("Upserted meeting to Pinecone: %s", record.meeting_id)
    elif record.status == "partial":
        logger.info(
            "Skipping Pinecone upsert for partial summary: %s (chars=%s)",
            record.meeting_id,
            record.raw_transcript_chars,
        )

    return record
```

**Step 5 — Modify the WebSocket disconnect handler** in `@app.websocket("/recall-audio-stream")`.

Currently the `except WebSocketDisconnect:` block only logs. Replace it with:

```python
except WebSocketDisconnect:
    logger.info("WebSocket disconnected — triggering ingestion pipeline")
    transcript = await state.get_transcript()
    if transcript and transcript != "[No transcript yet]":
        meeting_id = await state.get_bot_id() or f"mtg-{int(time.time())}"
        meeting_meta = {
            "meeting_id": meeting_id,
            "channel_id": SLACK_CHANNEL_ID,
            "channel_name": MEETING_CHANNEL_NAME,
            "start_ts": int(time.time()) - 3600,  # approximate; real start_ts from state if available
            "end_ts": int(time.time()),
            "duration_seconds": None,
            "participants": [],  # SummarizerAgent extracts participants from transcript
        }
        asyncio.create_task(run_ingestion_pipeline(transcript, meeting_meta))
    else:
        logger.info("No transcript to summarize on disconnect")
```

Note: `asyncio.create_task()` is used so the disconnect handler returns immediately (the pipeline runs in the background). This satisfies the "within 30 seconds" criterion without blocking the WebSocket teardown.

**Step 6 — Register the `/summarize` Slack slash command** using the Bolt SDK.

Add this after the module-level singleton init, inside a conditional block so it only registers when `slack_app` is not None:

```python
if slack_app is not None:
    @slack_app.command("/summarize")
    async def handle_summarize_command(ack, say, client, command):
        """Slack slash command: trigger ingestion pipeline and post structured summary."""
        await ack()  # Acknowledge within 3 seconds — Slack requirement

        transcript = await state.get_transcript()
        if not transcript or transcript == "[No transcript yet]":
            await say("No meeting transcript available yet. Is the bot in a meeting?")
            return

        meeting_id = await state.get_bot_id() or f"mtg-{int(time.time())}"
        meeting_meta = {
            "meeting_id": meeting_id,
            "channel_id": command.get("channel_id", SLACK_CHANNEL_ID),
            "channel_name": command.get("channel_name", MEETING_CHANNEL_NAME),
            "start_ts": int(time.time()) - 3600,
            "end_ts": int(time.time()),
            "duration_seconds": None,
            "participants": [],
        }

        try:
            record = await run_ingestion_pipeline(transcript, meeting_meta)
        except Exception as e:
            logger.error("Ingestion pipeline failed: %s", e)
            await say(f"Summary failed: {e}")
            return

        # Format structured summary for Slack
        action_items_text = "\n".join(
            f"  • {item.owner}: {item.task}" + (f" (due: {item.due})" if item.due else "")
            for item in record.action_items
        ) or "  None identified"

        decisions_text = "\n".join(f"  • {d}" for d in record.decisions) or "  None identified"
        topics_text = "\n".join(f"  • {t}" for t in record.topics_covered) or "  None identified"
        participants_text = ", ".join(record.participants) or "Unknown"

        status_tag = " _(partial — meeting may still be in progress)_" if record.status == "partial" else ""

        message = (
            f"*Meeting Summary*{status_tag}\n\n"
            f"*Participants:* {participants_text}\n\n"
            f"*Topics Discussed:*\n{topics_text}\n\n"
            f"*Decisions:*\n{decisions_text}\n\n"
            f"*Action Items:*\n{action_items_text}"
        )

        target_channel = command.get("channel_id", SLACK_CHANNEL_ID)
        await client.chat_postMessage(channel=target_channel, text=message)
```
